# Open Source Template

A reference repository for Virtual Minds employees who want to publish internal
code as open source. It collects the template files and short docs you need
once your project has been approved for release.

## Contents

- `LICENSES.md` - overview of every license offered here, with a short note on
  effects of each.
- `licenses/` - ready-to-copy license files. Drop the one you need into your
  project as `LICENSE`. Files whose name ends with `_template` contain
  placeholders (like `<YEAR>`) that must be filled in.

## Before you use this repository

This repo only ships the *files* a public project needs. The full open-source
release process - approvals, naming, attribution rules, mandatory notices,
security and IP review - lives in our internal documentation on Confluence space
"Open Source", ID is "OS". **Read that first.** If you have not yet been through
the approval process, this repository is not where you start.
