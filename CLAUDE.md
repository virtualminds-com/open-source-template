## Contribution guidelines

Changes to this repository must be made as atomic commits. Each commit is
self-sufficient and brings value. Commit titles must be limited to 50
characters, and commit message bodies must be wrapped at 80 characters.

Commit titles must use the imperative mood and start with a scope prefix
indicating what the change affects. For example, `license: add new one` or
`doc: clarify some links`.

Commit message bodies describe what was done in past tense, not imperative.

Changes to documentation and code comments must be concise, on point, and
must not reference any sort of legacy or 'backward compatibility'. Text
must read as if written from scratch.

All text in the repo must be wrapped at 80 symbols border unless it is
impossible (a long link, for example).
